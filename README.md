# Automation Ideas
## 1. A start-up launcher  
The idea is to only type "launch" on terminal which launch all start-up application that we might need. 
You could use the code to change it to your needs, below functionality was done for my own purpose. 

A launcher that launch: 
- VS Code
- Spotify
- Blackboard
- Focus timer with my different focus timer. For example

Monday - Friday 
The timer will display 4 buttons
1. One with 3 hour with display name "FYP: 3h" (Final Year Project)
2. One with 3 hour with display name "Other Modules: 3h"
3. One with 2 hour name "Standout"
4. One with 1 hour name "Job Application"

Saturday - Sunday
1. One with 3 hour "Standout"
2. One with 2 hour "Job Appliacation"

After each timer finish, I will have 5 button which will have break time 
1. 15 min break button 
2. 30 min break button 
3. 45 
4. 60 
5. or skip: if i press skip the display should show me all the option of different timer button depends on the day 

**Purpose:** Save time when trying to code, and just type launcher which launch what I wil need for the day.
